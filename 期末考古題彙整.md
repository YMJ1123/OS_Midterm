## 【題型 9】★★ Dekker's Solution 證明（2015 Q2a 考）

**章節 / 主題：** Ch6 Process Synchronization → Software Solutions to Critical Section、Dekker's Algorithm、Correctness Proof

**題目：** The first known correct software solution to the critical-section problem for two processes was developed by **Dekker**. The two processes, P₀ and P₁, share the following variables:

```c
boolean flag[2];   /* initially false */
int turn;
```

The structure of process Pᵢ (i == 0 or 1) is shown below; the other process is Pⱼ (j == 1 or 0). **Prove that the algorithm satisfies all three requirements** for the critical-section problem.

```c
do {
    flag[i] = true;
    while (flag[j]) {
        if (turn == j) {
            flag[i] = false;
            while (turn == j)
                ;  /* do nothing */
            flag[i] = true;
        }
    }
    /* critical section */
    turn = j;
    flag[i] = false;
    /* remainder section */
} while (true);
```

