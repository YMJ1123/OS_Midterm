## Q24｜Shared Memory — Calculate Σ n!
**（2011 Q6 / 2014 Q9）**

(20 pts / 10 pts) Complete the following program which calculates **Σ(n=1 to N) n!**. The value N is provided by users in the command line, i.e., N = atoi(argv[1]).

Hint: The size of an integer is 4 bytes. The program needs to create N child processes — one for each factorial calculation (i.e., n!). The child processes save the results in a shared integer memory and the parent process prints the final outcome. To prevent inconsistent results, parent needs to wait for each child process.

```c
#include <sys/shm.h>
#include <sys/stat.h>
#include <stdio.h>
#include <stdlib.h>
#include <unistd.h>
#include <sys/wait.h>

int main(int argc, char *argv[])
{
    int N = atoi(argv[1]);
    pid_t pid;
    int segment_id;
    int *shared_memory;

    // allocate and attach a shared memory segment
    __(A)__
    __(B)__

    __(C)__  // initialization

    for (__(D)__)  // create child processes
    {
        __(E)__

        if (__(F)__) {
            fprintf(stderr, "Fork Failed");
            exit(-1);
        } else if (__(G)__) {  // child part
            // do factorial calculation and save it
            __(H)__
            // then detach shared memory and exit
            __(I)__
        } else {  // parent part
            __(J)__
        }
    }

    printf("the result is %d\n", *shared_memory);

    // detach and remove the shared memory segment
    __(K)__
    __(L)__

    return 0;
}
```

## Q25｜Shared Memory — Calculate 2x+3y−5
**（2012 Q6 / 2015 Q9）**

(15 points) Please complete the following program that calculates equation **2x+3y−5**. The values of variables x and y are provided by users in the command line, i.e., x = atoi(argv[1]) and y = atoi(argv[2]).

Hint: the main program first allocates a shared memory and then creates two child processes — one for the x term calculation and one for the y term calculation. Save the results calculated in the child processes in the shared memory and print the final outcome in the parent process.

```c
#include <sys/shm.h>
#include <sys/stat.h>
#include <stdio.h>
#include <stdlib.h>
#include <unistd.h>
#include <sys/wait.h>

int main(int argc, char *argv[])
{
    int x = atoi(argv[1]);  // the value of variable x
    int y = atoi(argv[2]);  // the value of variable y
    int i;
    pid_t pid;
    const int sh_size = 4;  // shared memory size = 4 bytes

    // allocate a shared memory segment
    int segment_id = __(A)__(IPC_PRIVATE, sh_size, S_IRUSR | S_IWUSR);
    // attach the shared memory segment
    int *shared_memory = (int *) __(B)__(segment_id, NULL, 0);

    *shared_memory = __(C)__;  // initialization

    for (i = 2; i > 0; i--)  // create two child processes
    {
        pid = __(D)__();

        if (pid < 0) {
            fprintf(stderr, "Fork Failed");
            exit(-1);
        } else if (pid == __(E)__) {  // child part
            if (__(F)__)  // do x term calculation
            if (__(G)__)  // do y term calculation

            // detach the shared memory segment and exit
            shmdt(shared_memory);
            exit(0);
        } else {  // parent part
            __(H)__;
        }
    }

    *shared_memory -= 5;
    printf("the result is %d\n", *shared_memory);
    // detach the shared memory segment
    shmdt(shared_memory);
    // remove the shared memory segment
    __(I)__(segment_id, IPC_RMID, NULL);

    return 0;
}
```
