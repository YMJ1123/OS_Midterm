## Q2 — Scheduler Activation: Problem & How It Works (Topic 20)
**Result: ✅ Correct (concepts present, expression needs polish)**

**Your answer (summary):** M:M model problem — when a blocking system call happens, the kernel thread is blocked, reducing available kernel threads for user threads until none can run. Scheduler Activation: kernel detects the blocking → upcall to thread library → upcall handler switches from T1 to T2 on LWP → when I/O completes, kernel upcalls again → T1 returns to ready.

**Verdict:** All key terms mentioned (upcall, upcall handler, LWP). Flow is correct. Tip: write "LWP" clearly on the exam, and emphasize that upcall handler *saves the blocked thread's state* before scheduling another.
